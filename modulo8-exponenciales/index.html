Módulo 8: Integrales Exponenciales

Teoría, laboratorio interactivo y ejemplos resueltos

Sección 1: Teoría y Fórmulas Básicas

Una función exponencial tiene la variable en el exponente. Su integral se obtiene recordando que la derivada de \(e^u\) es \(e^u\) multiplicada por la derivada de \(u\). Al revertir ese proceso, aparece la fórmula básica:

\(\int e^u\,du = e^u + C\)

Para una base a distinta de e (con \(a > 0\) y \(a \neq 1\)) usamos el hecho de que \(\frac{d}{dx}(a^x) = a^x \ln a\). Dividiendo entre \(\ln a\) se obtiene:

\(\int a^x\,dx = \frac{a^x}{\ln a} + C \qquad (a > 0,\ a \neq 1)\)
Diferencia clave: al integrar \(e^x\), la función se queda igual: \(\int e^x\,dx = e^x + C\), porque \(\ln e = 1\) y no hay que dividir entre nada. Al integrar \(a^x\) con base distinta de \(e\), aparece el factor \(\frac{1}{\ln a}\), que corrige la derivada \(\ln a\) que se genera al derivar \(a^x\).

Sección 3: Ejemplos Resueltos Paso a Paso

Ejemplo 1: \(\int (e^{2x} + 3e^x)\,dx\)

Paso 1: Separar término a término
\(\int (e^{2x} + 3e^x)\,dx = \int e^{2x}\,dx + \int 3e^x\,dx\)
Usamos la propiedad de linealidad: la integral de una suma es la suma de las integrales, y una constante (\(3\)) puede salir de la integral.
Paso 2: Integrar \(e^{2x}\) con regla de la cadena inversa
\(\int e^{2x}\,dx = \frac{1}{2}e^{2x} + C_1\)
Sea \(u = 2x\), entonces \(du = 2\,dx\) y \(dx = \frac{du}{2}\). Reemplazamos: \(\int e^{u}\cdot\frac{du}{2} = \frac{1}{2}\int e^u\,du = \frac{1}{2}e^u + C_1 = \frac{1}{2}e^{2x} + C_1\). El 1/2 aparece porque \(du = 2\,dx\): la derivada interna del exponente (el 2) debe dividirse.
Paso 3: Integrar \(3e^x\)
\(\int 3e^x\,dx = 3\int e^x\,dx = 3e^x + C_2\)
Aquí la derivada interna es 1, así que no hay factor adicional. El \(3\) se conserva por linealidad.
Paso 4: Resultado final
\(\int (e^{2x} + 3e^x)\,dx = \frac{1}{2}e^{2x} + 3e^x + C\)
Las constantes \(C_1\) y \(C_2\) se agrupan en una sola constante \(C = C_1 + C_2\).
Comprobación: \(\frac{d}{dx}\left(\frac{1}{2}e^{2x} + 3e^x\right) = \frac{1}{2}\cdot 2e^{2x} + 3e^x = e^{2x} + 3e^x\) ✔

Ejemplo 2: \(\int \frac{dx}{e^x + e^{-x}}\)

Paso 1: Multiplicar numerador y denominador por \(e^x\)
\(\int \frac{dx}{e^x + e^{-x}} = \int \frac{e^x}{e^x\left(e^x + e^{-x}\right)}\,dx\)
\(= \int \frac{e^x}{e^{2x} + e^{0}}\,dx\)
Multiplicamos arriba y abajo por \(e^x\) (esto no cambia el valor, porque \(\frac{e^x}{e^x} = 1\)). Al distribuir en el denominador, \(e^x\cdot e^x = e^{2x}\) y \(e^x\cdot e^{-x} = e^{0} = 1\), por la ley de exponentes \(a^m\cdot a^n = a^{m+n}\).
Paso 2: Simplificar el denominador
\(\int \frac{e^x}{e^{2x} + 1}\,dx\)
Como \(e^0 = 1\), el denominador queda \(e^{2x} + 1\).
Paso 3: Sustitución \(u = e^x\)
\(u = e^x \quad \Rightarrow \quad du = e^x\,dx \quad \Rightarrow \quad e^x\,dx = du\)
\(e^{2x} = (e^x)^2 = u^2\)
\(\int \frac{e^x}{e^{2x}+1}\,dx = \int \frac{du}{u^2 + 1}\)
La derivada de \(e^x\) es \(e^x\), que aparece exactamente en el numerador, así que \(e^x\,dx\) se convierte en \(du\) sin constante adicional. El \(e^{2x}\) se reescribe como \(u^2\) usando \((a^m)^n = a^{mn}\).
Paso 4: Integrar la fórmula del arcotangente
\(\int \frac{du}{u^2 + 1} = \arctan(u) + C\)
Esta es una fórmula estándar de integrales trigonométricas inversas.
Paso 5: Volver a la variable x
\(\int \frac{dx}{e^x + e^{-x}} = \arctan(e^x) + C\)
Comprobación: \(\frac{d}{dx}\arctan(e^x) = \frac{1}{1+(e^x)^2}\cdot e^x = \frac{e^x}{e^{2x}+1} = \frac{1}{e^x+e^{-x}}\) ✔
