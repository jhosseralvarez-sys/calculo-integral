Módulo 2: Regla del Trapecio

1. Teoría y Historia

La Regla del Trapecio es un método numérico para aproximar integrales definidas. En lugar de usar rectángulos como en la regla del punto medio o las sumas de Riemann, esta técnica utiliza trapecios para estimar el área bajo la curva.

Geométricamente, la idea es dividir el intervalo \([a, b]\) en \(n\) subintervalos iguales de ancho \(\Delta x = \frac{b-a}{n}\) y aproximar el área bajo la curva \(f(x)\) en cada subintervalo como un trapecio.

La fórmula matemática de la Regla del Trapecio es:

\[ T_n = \frac{\Delta x}{2} \left[ f(x_0) + 2\sum_{i=1}^{n-1} f(x_i) + f(x_n) \right] \] donde \(\Delta x = \frac{b-a}{n}\) y \(x_i = a + i\Delta x\).

La Regla del Trapecio puede sobreestimar o subestimar el área real dependiendo de la concavidad de la función:

  • Cuando la función es cóncava hacia arriba (\(f''(x) > 0\)), la regla tiende a sobreestimar el área real.
  • Cuando la función es cóncava hacia abajo (\(f''(x) < 0\)), la regla tiende a subestimar el área real.

3. Ejemplos Resueltos Paso a Paso

Ejemplo 1: Aproximar \(\int_0^2 x^2 \, dx\) con \(n=4\)

Primero calculamos \(\Delta x\):

\[ \Delta x = \frac{b-a}{n} = \frac{2-0}{4} = 0.5 \]

Los puntos \(x_i\) y sus valores \(f(x_i) = x_i^2\):

\(i\) \(x_i\) \(f(x_i) = x_i^2\)
0 0.0 0.0000
1 0.5 0.2500
2 1.0 1.0000
3 1.5 2.2500
4 2.0 4.0000
Sustituimos en la fórmula de la Regla del Trapecio: \[ T_4 = \frac{\Delta x}{2} \left[ f(x_0) + 2(f(x_1) + f(x_2) + f(x_3)) + f(x_4) \right] \]
\[ T_4 = \frac{0.5}{2} \left[ 0 + 2(0.25 + 1.00 + 2.25) + 4.00 \right] \]
\[ T_4 = 0.25 \left[ 0 + 2(3.50) + 4.00 \right] = 0.25 \left[ 0 + 7.00 + 4.00 \right] = 0.25 \times 11.00 = 2.75 \]

El valor exacto es \(\frac{8}{3} \approx 2.6667\), por lo tanto, el error es \(|2.75 - 2.6667| = 0.0833\).

Ejemplo 2: Aproximar \(\int_1^3 \frac{1}{x} \, dx\) con \(n=5\)

Calculamos \(\Delta x\):

\[ \Delta x = \frac{b-a}{n} = \frac{3-1}{5} = 0.4 \]

Los puntos \(x_i\) y sus valores \(f(x_i) = \frac{1}{x_i}\):

\(i\) \(x_i\) \(f(x_i) = \frac{1}{x_i}\)
0 1.0 1.0000
1 1.4 0.7143
2 1.8 0.5556
3 2.2 0.4545
4 2.6 0.3846
5 3.0 0.3333
Aplicamos la fórmula de la Regla del Trapecio: \[ T_5 = \frac{\Delta x}{2} \left[ f(x_0) + 2\sum_{i=1}^{4} f(x_i) + f(x_5) \right] \]
\[ T_5 = \frac{0.4}{2} \left[ 1.0000 + 2(0.7143 + 0.5556 + 0.4545 + 0.3846) + 0.3333 \right] \]
\[ T_5 = 0.2 \left[ 1.0000 + 2(2.1090) + 0.3333 \right] = 0.2 \left[ 1.0000 + 4.2180 + 0.3333 \right] \]
\[ T_5 = 0.2 \times 5.5513 = 1.1103 \]

El valor exacto es \(\ln(3) - \ln(1) = \ln(3) \approx 1.0986\), por lo tanto, el error es \(|1.1103 - 1.0986| = 0.0117\).
