Módulo 6: Integración Directa

SECCIÓN 1: Teoría y Fórmulas Básicas

Integración Directa: Es el proceso inverso a la derivación. Consiste en encontrar una función original a partir de su derivada conocida. Se llama "directa" porque se aplican fórmulas de integración inmediatas sin necesidad de métodos complejos.

Constante de Integración (C): Al integrar, siempre se añade una constante C porque la derivada de una constante es cero. Esto significa que hay infinitas antiderivadas posibles que difieren solo en una constante.

Familia de Curvas: Las diferentes antiderivadas forman una familia de curvas paralelas entre sí, donde cada miembro de la familia corresponde a un valor distinto de C.

\[\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad \text{(para } n \neq -1\text{)}\]

\[\int \frac{1}{x} dx = \ln|x| + C\]

\[\int e^x dx = e^x + C\]

\[\int \sin x dx = -\cos x + C \quad \text{y} \quad \int \cos x dx = \sin x + C\]

SECCIÓN 3: Ejemplos Resueltos Paso a Paso

Ejemplo 1 (Polinómica):
\[\int (3x^2 - 2x + 1) dx\]
Aplicamos la fórmula de la potencia a cada término:
\[\int 3x^2 dx = 3 \cdot \frac{x^{2+1}}{2+1} = 3 \cdot \frac{x^3}{3} = x^3\]
\[\int -2x dx = -2 \cdot \frac{x^{1+1}}{1+1} = -2 \cdot \frac{x^2}{2} = -x^2\]
\[\int 1 dx = x\]
Combinando todos los términos y añadiendo la constante:
\[\boxed{\int (3x^2 - 2x + 1) dx = x^3 - x^2 + x + C}\]
Ejemplo 2 (Radicales y Fracciones):
\[\int \left(\frac{1}{x} + \frac{1}{\sqrt{x}}\right) dx\]
Reescribimos las expresiones para facilitar la integración:
\[\frac{1}{x} = x^{-1} \quad \text{y} \quad \frac{1}{\sqrt{x}} = x^{-1/2}\]
Ahora integramos cada término:
\[\int x^{-1} dx = \ln|x|\]
\[\int x^{-1/2} dx = \frac{x^{-1/2+1}}{-1/2+1} = \frac{x^{1/2}}{1/2} = 2\sqrt{x}\]
Combinando resultados:
\[\boxed{\int \left(\frac{1}{x} + \frac{1}{\sqrt{x}}\right) dx = \ln|x| + 2\sqrt{x} + C}\]
Ejemplo 3 (Trigonométrica/Exponencial):
\[\int (e^x + \sin x) dx\]
Integramos cada término por separado:
\[\int e^x dx = e^x\]
\[\int \sin x dx = -\cos x\]
Combinando los resultados:
\[\boxed{\int (e^x + \sin x) dx = e^x - \cos x + C}\]
