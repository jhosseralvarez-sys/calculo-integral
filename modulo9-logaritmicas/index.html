Módulo 9: Integrales Logarítmicas

Teoría, laboratorio interactivo y ejemplos resueltos

Sección 1: Teoría y Fórmulas Básicas

Algunas integrales tienen la forma de un cociente cuyo numerador es la derivada del denominador. Al integrarlas aparece el logaritmo natural. Es la integral inversa de la derivada \(\frac{d}{du}\ln|u| = \frac{1}{u}\).

\(\int \frac{du}{u} = \ln|u| + C\)

¿Por qué aparece el valor absoluto?

El logaritmo natural \(\ln t\) solo está definido para \(t > 0\). Pero la función \(\frac{1}{u}\) sí existe para valores negativos de \(u\), por ejemplo \(u = -2\). Si escribiéramos \(\ln u\), la fórmula fallaría en todo el intervalo \(u < 0\). Con \(\ln|u|\) la fórmula sirve en ambos lados del cero, porque \(\frac{d}{du}\ln|u| = \frac{1}{u}\) vale tanto para \(u > 0\) como para \(u < 0\).

Cuándo completar el cuadrado

Si el denominador es un polinomio de segundo grado que no se factoriza fácilmente, conviene completar el cuadrado. Eso lo transforma en una suma o diferencia de cuadrados. Según el caso, la integral resultante puede ser un logaritmo o un arcotangente:

Regla práctica: si el numerador es la derivada del denominador, usa \(\ln|u|\). Si el denominador queda como \(u^2 + k^2\) después de completar el cuadrado, usa el arcotangente.

Sección 3: Ejemplos Resueltos Paso a Paso

Ejemplo 1: \(\int \frac{dx}{x \ln x}\)

Paso 1: Identificar u y calcular du
\(u = \ln x \quad \Rightarrow \quad du = \frac{1}{x}\,dx\)
Elegimos \(u\) como el logaritmo porque su derivada \(\frac{1}{x}\) aparece en el integrando. La regla usada es \(\frac{d}{dx}\ln x = \frac{1}{x}\).
Paso 2: Reemplazar
\(\int \frac{dx}{x\ln x} = \int \frac{1}{\ln x}\cdot\frac{dx}{x} = \int \frac{du}{u}\)
El factor \(\frac{1}{x}\,dx\) se convierte en \(du\), y el \(\ln x\) del denominador se convierte en \(u\).
Paso 3: Integrar y volver a x
\(\int \frac{du}{u} = \ln|u| + C = \ln|\ln x| + C\)
Aplicamos la fórmula básica \(\int \frac{du}{u} = \ln|u| + C\). Como \(u = \ln x\), el resultado es \(\ln|\ln x| + C\).
Comprobación: \(\frac{d}{dx}\ln|\ln x| = \frac{1}{\ln x}\cdot\frac{1}{x} = \frac{1}{x\ln x}\) ✔

Ejemplo 2: \(\int \frac{dx}{x(\ln x)^2}\)

Paso 1: Sustitución \(u = \ln x\)
\(u = \ln x \quad \Rightarrow \quad du = \frac{1}{x}\,dx\)
Igual que en el ejemplo anterior, \(\frac{1}{x}\,dx\) es exactamente \(du\).
Paso 2: Reemplazar
\(\int \frac{dx}{x(\ln x)^2} = \int \frac{1}{(\ln x)^2}\cdot\frac{dx}{x} = \int \frac{du}{u^2} = \int u^{-2}\,du\)
Aquí el denominador tiene una potencia, \((\ln x)^2 = u^2\), así que el integrando queda como \(u^{-2}\).
Paso 3: Aplicar la regla de potencias
\(\int u^{-2}\,du = \frac{u^{-2+1}}{-2+1} + C = \frac{u^{-1}}{-1} + C = -u^{-1} + C\)
Usamos \(\int u^n\,du = \frac{u^{n+1}}{n+1} + C\) con \(n = -2\), así que \(n+1 = -1\). Como no es \(-1\) en el exponente de \(u\) sino que es \(n\) lo que vale \(-2\), la fórmula de potencias sí aplica. Dividir entre \(-1\) cambia el signo.
Paso 4: Volver a la variable x
\(\int \frac{dx}{x(\ln x)^2} = -\frac{1}{u} + C = -\frac{1}{\ln x} + C\)
Comprobación: \(\frac{d}{dx}\left(-\frac{1}{\ln x}\right) = \frac{1}{(\ln x)^2}\cdot\frac{1}{x} = \frac{1}{x(\ln x)^2}\) ✔

Ejemplo 3: \(\int \frac{dx}{x^2+2x+2}\)

Paso 1: Completar el cuadrado en el denominador
\(x^2 + 2x + 2 = (x^2 + 2x + 1) + 1 = (x+1)^2 + 1\)
Tomamos la mitad del coeficiente de \(x\), que es \(\frac{2}{2} = 1\), y lo elevamos al cuadrado: \(1^2 = 1\). Sumamos y restamos ese 1 para formar el trinomio cuadrado perfecto \((x+1)^2\).
Paso 2: Sustitución \(u = x+1\)
\(u = x+1 \quad \Rightarrow \quad du = dx\)
\(\int \frac{dx}{x^2+2x+2} = \int \frac{dx}{(x+1)^2+1} = \int \frac{du}{u^2+1}\)
Como \(du = dx\), no aparece ningún factor adicional. El denominador ya tiene la forma \(u^2 + 1\).
Paso 3: Aplicar la fórmula del arcotangente
\(\int \frac{du}{u^2+1} = \arctan(u) + C\)
Esta es la fórmula estándar \(\int \frac{du}{u^2 + a^2} = \frac{1}{a}\arctan\frac{u}{a} + C\) con \(a = 1\), así que el factor \(\frac{1}{a}\) vale 1 y no aparece.
Paso 4: Volver a la variable x
\(\int \frac{dx}{x^2+2x+2} = \arctan(x+1) + C\)
Comprobación: \(\frac{d}{dx}\arctan(x+1) = \frac{1}{1+(x+1)^2} = \frac{1}{x^2+2x+2}\) ✔
