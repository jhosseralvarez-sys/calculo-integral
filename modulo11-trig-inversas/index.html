Módulo 11: Integrales que Conducen a Trigonométricas Inversas

Teoría, laboratorio interactivo y ejemplos resueltos

Sección 1: Teoría y Fórmulas Básicas

Algunas integrales de funciones algebraicas no se resuelven con potencias ni logaritmos, sino que dan como resultado funciones trigonométricas inversas. Esto ocurre cuando el integrando tiene la forma de una raíz en el denominador o de una suma de cuadrados. Las dos fórmulas de referencia son:

\(\int \frac{du}{\sqrt{1 - u^2}} = \arcsin u + C\)
\(\int \frac{du}{1 + u^2} = \arctan u + C\)

La primera corresponde a la derivada \(\frac{d}{du}\arcsin u = \frac{1}{\sqrt{1-u^2}}\), y la segunda a \(\frac{d}{du}\arctan u = \frac{1}{1+u^2}\). Al integrar, simplemente leemos la derivada al revés.

Sustitución previa: casi nunca la integral aparece en la forma exacta de estas fórmulas. Con frecuencia hay que completar el cuadrado en el polinomio bajo la raíz o en el denominador, y después hacer una sustitución lineal \(u = \) (algo) para encajar en \(\sqrt{1-u^2}\) o en \(1+u^2\). Los coeficientes que aparecen en el proceso salen de esa sustitución, y se estudian en la Sección 3.

Sección 3: Ejemplos Resueltos Paso a Paso

Ejemplo 1: \(\int \frac{3+x}{\sqrt{1-x^2}}\,dx\)

Paso 1: Separar la integral en dos
\(\int \frac{3+x}{\sqrt{1-x^2}}\,dx = \int \frac{3}{\sqrt{1-x^2}}\,dx + \int \frac{x}{\sqrt{1-x^2}}\,dx\)
Usamos la linealidad de la integral: la integral de una suma es la suma de las integrales. El numerador \(3 + x\) se reparte entre los dos términos de la fracción.
Paso 2: Primera integral (forma de arcoseno)
\(\int \frac{3}{\sqrt{1-x^2}}\,dx = 3\int \frac{dx}{\sqrt{1-x^2}} = 3\arcsin x + C_1\)
El factor 3 sale de la integral porque es constante. Luego aplicamos la fórmula \(\int \frac{du}{\sqrt{1-u^2}} = \arcsin u + C\) con \(u = x\).
Paso 3: Segunda integral (sustitución \(u = 1 - x^2\))
\(u = 1 - x^2 \quad \Rightarrow \quad du = -2x\,dx \quad \Rightarrow \quad x\,dx = -\frac{du}{2}\)
\(\int \frac{x}{\sqrt{1-x^2}}\,dx = \int \frac{1}{\sqrt{u}}\cdot\left(-\frac{du}{2}\right) = -\frac{1}{2}\int u^{-1/2}\,du\)
\(= -\frac{1}{2}\cdot\frac{u^{1/2}}{\tfrac12} + C_2 = -u^{1/2} + C_2 = -\sqrt{1-x^2} + C_2\)
El \(-\frac{1}{2}\) aparece porque \(du = -2x\,dx\): al despejar \(x\,dx\) dividimos entre \(-2\). Luego usamos \(\int u^n\,du = \frac{u^{n+1}}{n+1} + C\) con \(n = -\tfrac12\), así que \(n+1 = \tfrac12\). Dividir entre \(\tfrac12\) multiplica por 2, y ese 2 se cancela con el \(-\tfrac12\) para dejar \(-1\).
Paso 4: Sumar los resultados
\(\int \frac{3+x}{\sqrt{1-x^2}}\,dx = 3\arcsin x - \sqrt{1-x^2} + C\)
Las constantes \(C_1\) y \(C_2\) se agrupan en una sola constante \(C\).
Comprobación: \(\frac{d}{dx}\left(3\arcsin x - \sqrt{1-x^2}\right) = \frac{3}{\sqrt{1-x^2}} + \frac{x}{\sqrt{1-x^2}} = \frac{3+x}{\sqrt{1-x^2}}\) ✔

Ejemplo 2: \(\int \frac{dx}{\sqrt{4x - x^2}}\)

Paso 1: Completar el cuadrado bajo la raíz
\(4x - x^2 = -(x^2 - 4x) = -\left[(x-2)^2 - 4\right] = 4 - (x-2)^2\)
Sacamos el signo menos como factor común, completamos el cuadrado con \(\left(\frac{-4}{2}\right)^2 = 4\) y sumamos y restamos ese 4 dentro del paréntesis. Al distribuir el signo menos, el \(-(-4) = +4\) queda en la expresión final.
Paso 2: Reescribir la integral
\(\int \frac{dx}{\sqrt{4 - (x-2)^2}}\)
Ahora la forma se parece a \(\frac{1}{\sqrt{a^2 - t^2}}\), con \(a = 2\) y \(t = x - 2\).
Paso 3: Sustitución \(u = \frac{x-2}{2}\)
\(u = \frac{x-2}{2} \quad \Rightarrow \quad du = \frac{dx}{2} \quad \Rightarrow \quad dx = 2\,du\)
\(\sqrt{4 - (x-2)^2} = \sqrt{4 - 4u^2} = 2\sqrt{1-u^2}\)
\(\int \frac{2\,du}{2\sqrt{1-u^2}} = \int \frac{du}{\sqrt{1-u^2}}\)
Dividimos \(x - 2\) entre 2 para tener \(u\) con la forma \(1 - u^2\). Como \(x - 2 = 2u\), el denominador queda \(2\sqrt{1-u^2}\). El factor 2 del \(dx = 2\,du\) se cancela con el 2 del denominador.
Paso 4: Aplicar la fórmula del arcoseno y volver a x
\(\int \frac{du}{\sqrt{1-u^2}} = \arcsin u + C = \arcsin\left(\frac{x-2}{2}\right) + C\)
Comprobación: \(\frac{1}{\sqrt{1-\left(\frac{x-2}{2}\right)^2}}\cdot\frac{1}{2} = \frac{1}{\sqrt{4-(x-2)^2}} = \frac{1}{\sqrt{4x-x^2}}\) ✔

Ejemplo 3: \(\int \frac{dx}{x^2 + 6x + 10}\)

Paso 1: Completar el cuadrado en el denominador
\(x^2 + 6x + 10 = (x^2 + 6x + 9) + 1 = (x+3)^2 + 1\)
Tomamos la mitad de 6, que es 3, y lo elevamos al cuadrado: \(3^2 = 9\). Sumamos y restamos 9 para formar el trinomio cuadrado perfecto.
Paso 2: Sustitución \(u = x + 3\)
\(u = x + 3 \quad \Rightarrow \quad du = dx\)
\(\int \frac{dx}{(x+3)^2+1} = \int \frac{du}{u^2+1}\)
Como \(du = dx\), no aparece ningún factor adicional. El denominador ya tiene la forma \(u^2 + 1\).
Paso 3: Aplicar la fórmula del arcotangente y volver a x
\(\int \frac{du}{u^2+1} = \arctan u + C = \arctan(x+3) + C\)
Comprobación: \(\frac{d}{dx}\arctan(x+3) = \frac{1}{1+(x+3)^2} = \frac{1}{x^2+6x+10}\) ✔
