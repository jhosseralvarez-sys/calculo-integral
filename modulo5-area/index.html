Módulo 5: Integral Definida y Área bajo la Curva

Teoría y El Teorema Fundamental del Cálculo

Teorema Fundamental del Cálculo (TFC)

El Teorema Fundamental del Cálculo establece la relación entre la derivación y la integración. Si \(F(x)\) es una antiderivada de \(f(x)\), entonces:

\[\int_a^b f(x) dx = F(b) - F(a)\]

Este teorema permite calcular integrales definidas usando antiderivadas.

Integral Definida vs Área Geométrica

Integral Definida: Puede ser positiva, negativa o cero dependiendo de si la función está por encima, por debajo o cruza el eje X en el intervalo \([a,b]\).

Área Geométrica: Siempre es positiva, ya que representa el área total entre la curva y el eje X. Se calcula como:

\[\int_a^b |f(x)| dx\]

Área entre dos curvas

Para encontrar el área entre dos curvas \(f(x)\) y \(g(x)\) desde \(x=a\) hasta \(x=b\), usamos:

\[A = \int_a^b |f(x) - g(x)| dx\]

Laboratorio Interactivo

Visualizador A: Área bajo la curva \(f(x) = x^2 - 1\)

\(F(b) - F(a) = \int_a^b (x^2 - 1) dx =\) 0.00

Visualizador B: Área entre \(f(x) = 2x\) y \(g(x) = x^2\)

\(\int_a^b |2x - x^2| dx =\) 0.00

Ejemplos Resueltos Paso a Paso

Ejemplo 1: Integral Definida

Calcular \(\int_0^2 (3x^2 - 2x + 1) dx\)

Paso 1: Hallar la antiderivada
\[F(x) = \int (3x^2 - 2x + 1) dx = x^3 - x^2 + x + C\]
Paso 2: Aplicar el Teorema Fundamental del Cálculo
\[\int_0^2 (3x^2 - 2x + 1) dx = F(2) - F(0)\]
Paso 3: Sustituir los límites
\(F(2) = 2^3 - 2^2 + 2 = 8 - 4 + 2 = 6\)
\(F(0) = 0^3 - 0^2 + 0 = 0\)
\[\int_0^2 (3x^2 - 2x + 1) dx = 6 - 0 = 6\]

Ejemplo 2: Área entre curvas

Determinar el área de la región limitada por \(f(x) = x^2\) y \(g(x) = 2x\).

Paso 1: Hallar los puntos de intersección
Igualamos las funciones: \(x^2 = 2x\)
\(x^2 - 2x = 0\) → \(x(x - 2) = 0\) → \(x = 0\) o \(x = 2\)
Los puntos de intersección son \((0,0)\) y \((2,4)\).
Paso 2: Plantear la integral
En el intervalo \([0,2]\), \(2x \geq x^2\), por lo tanto:
\[A = \int_0^2 (2x - x^2) dx\]
Paso 3: Resolver la integral
\[A = \left[ x^2 - \frac{x^3}{3} \right]_0^2 = \left(4 - \frac{8}{3}\right) - (0) = \frac{12 - 8}{3} = \frac{4}{3}\]
El área es \(\frac{4}{3}\) unidades cuadradas.
