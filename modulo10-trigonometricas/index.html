Módulo 10: Integrales Trigonométricas

Teoría, laboratorio interactivo y ejemplos resueltos

Sección 1: Teoría y Fórmulas Básicas

Las integrales trigonométricas básicas son las inversas de las derivadas de las funciones trigonométricas. Si recuerdas que \(\frac{d}{du}\cos u = -\sin u\) o que \(\frac{d}{du}\tan u = \sec^2 u\), puedes revertir cada derivada para obtener la integral correspondiente.

Seno\(\int \sin u \, du = -\cos u + C\)
Coseno\(\int \cos u \, du = \sin u + C\)
Tangente\(\int \tan u \, du = -\ln|\cos u| + C\)
Secante cuadrada\(\int \sec^2 u \, du = \tan u + C\)
Cosecante cuadrada\(\int \csc^2 u \, du = -\cot u + C\)
Importancia de las identidades: muchas integrales no se resuelven directamente con estas fórmulas. Antes de integrar conviene simplificar con identidades como \(\sin^2 x + \cos^2 x = 1\), \(\tan x = \frac{\sin x}{\cos x}\) o las fórmulas de ángulo doble, por ejemplo \(\sin 2x = 2\sin x\cos x\). Una expresión más simple casi siempre se integra con menos esfuerzo.

Sección 3: Ejemplos Resueltos Paso a Paso

Ejemplo 1: \(\int \sec^2 y \cos y \, dy\)

Paso 1: Simplificar con identidades
\(\sec^2 y \cos y = \frac{1}{\cos^2 y}\cdot\cos y = \frac{1}{\cos y} = \sec y\)
Usamos \(\sec y = \frac{1}{\cos y}\). Al elevar al cuadrado, \(\sec^2 y = \frac{1}{\cos^2 y}\). Luego uno de los factores \(\cos y\) del denominador cancela con el \(\cos y\) del numerador.
Paso 2: Integrar \(\sec y\)
\(\int \sec^2 y \cos y \, dy = \int \sec y \, dy = \ln|\sec y + \tan y| + C\)
\(\int \sec y\,dy\) no se resuelve con una fórmula directa de tabla; se obtiene multiplicando y dividiendo por \(\sec y + \tan y\). Es un resultado estándar que conviene memorizar.
Resultado: \(\int \sec^2 y \cos y \, dy = \ln|\sec y + \tan y| + C\)

Ejemplo 2: \(\int (\cos x - \sin x)^2 \, dx\)

Paso 1: Expandir el binomio al cuadrado
\((\cos x - \sin x)^2 = \cos^2 x - 2\sin x\cos x + \sin^2 x\)
Aplicamos \((a - b)^2 = a^2 - 2ab + b^2\) con \(a = \cos x\) y \(b = \sin x\).
Paso 2: Aplicar identidades
\(\cos^2 x + \sin^2 x = 1\) y \(2\sin x\cos x = \sin(2x)\)
\(\cos^2 x - 2\sin x\cos x + \sin^2 x = 1 - \sin(2x)\)
La identidad pitagórica agrupa \(\cos^2 x + \sin^2 x\) en 1. La fórmula de ángulo doble transforma \(2\sin x\cos x\) en \(\sin 2x\). El signo menos del término medio se conserva.
Paso 3: Integrar término a término
\(\int (1 - \sin 2x)\,dx = \int 1\,dx - \int \sin 2x\,dx\)
\(\int 1\,dx = x\)
\(\int \sin 2x\,dx = -\frac{1}{2}\cos 2x\)
Para \(\int \sin 2x\,dx\) usamos \(u = 2x\), \(du = 2\,dx\), así que \(dx = \frac{du}{2}\). Entonces \(\int \sin u \cdot \frac{du}{2} = \frac{1}{2}(-\cos u) = -\frac{1}{2}\cos 2x\). El \(\frac{1}{2}\) aparece porque \(du = 2\,dx\).
Paso 4: Resultado final
\(\int (\cos x - \sin x)^2\,dx = x - \left(-\frac{1}{2}\cos 2x\right) + C = x + \frac{1}{2}\cos 2x + C\)
Comprobación: \(\frac{d}{dx}\left(x + \tfrac{1}{2}\cos 2x\right) = 1 - \sin 2x\) ✔

Ejemplo 3: \(\int \frac{dx}{\cos^2 x \sqrt{\tan x - 1}}\)

Paso 1: Reconocer \(\sec^2 x\)
\(\frac{1}{\cos^2 x} = \sec^2 x\)
Por definición \(\sec x = \frac{1}{\cos x}\), así que \(\sec^2 x = \frac{1}{\cos^2 x}\). La integral queda \(\int \frac{\sec^2 x}{\sqrt{\tan x - 1}}\,dx\).
Paso 2: Sustitución \(u = \tan x - 1\)
\(u = \tan x - 1 \quad \Rightarrow \quad du = \sec^2 x\,dx\)
Derivamos: \(\frac{d}{dx}\tan x = \sec^2 x\) y \(\frac{d}{dx}(-1) = 0\). Por eso \(\sec^2 x\,dx\) se convierte exactamente en \(du\), sin factor adicional.
Paso 3: Integrar en u
\(\int \frac{\sec^2 x}{\sqrt{\tan x - 1}}\,dx = \int u^{-1/2}\,du\)
\(= \frac{u^{1/2}}{\tfrac{1}{2}} + C = 2u^{1/2} + C\)
Usamos \(\int u^n\,du = \frac{u^{n+1}}{n+1} + C\) con \(n = -\tfrac12\), así que \(n+1 = \tfrac12\). Dividir entre \(\tfrac12\) equivale a multiplicar por 2.
Paso 4: Volver a la variable x
\(\int \frac{dx}{\cos^2 x\sqrt{\tan x - 1}} = 2\sqrt{\tan x - 1} + C\)
Comprobación: \(\frac{d}{dx}\left(2\sqrt{\tan x - 1}\right) = \frac{1}{\sqrt{\tan x - 1}}\cdot\sec^2 x\) ✔
